# 👥 Employee Attrition Analysis (SQL)

## Overview
SQL-based analysis of employee data to understand which factors are linked to attrition.

## Tools Used
SQL (MySQL)

## SQL Skills Demonstrated
Aggregations, Joins, Subqueries, Views, CTEs, Window Functions

## What I Did
- Designed a two-table database modeling 10,000 employee records
- Wrote SQL queries to analyze workforce metrics across departments and tenure

## Key Findings
- Employees working overtime had a **12.18%** attrition rate, compared to **7.78%** for non-overtime staff
